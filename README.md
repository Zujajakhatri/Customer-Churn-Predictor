# Customer Churn Prediction

End-to-end ML project predicting telecom customer churn.

## Files
- `customer_churn_data.csv` – dataset
- `model_training.ipynb` – notebook (EDA, preprocessing, training, evaluation)
- `churn_pipeline.pkl` – saved sklearn pipeline (preprocessing + model)
- `app.py` – Streamlit web app
- `requirements.txt` – dependencies

## How to run
pip install -r requirements.txt
streamlit run app.py
